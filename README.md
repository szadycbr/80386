# 80386
Tiny 80386 pc emulator in single html file, no need to complicate.
One and only, from scratch PC emulator in single html file 

80386DX at 33 MHz with 32-bit registers, protected mode and paging, 16 MB RAM, IBM VGA with CGA/EGA/VGA modes, DAC palette, Sound Blaster 2.0 (DSP 2.01 + OPL2 FM) and PC speaker. One unified 33 MHz clock domain: CPU + 8254 PIT + VGA vertical retrace + Sound Blaster DMA share the same clocks.
